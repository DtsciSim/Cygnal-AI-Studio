## Why Cygnal?

Most people juggle 6–8 tools: a browser, a chat app, a notes app, a file manager, a prompt doc, an automation tool, and Jupyter.

**Cygnal puts them side-by-side in one calm Windows workspace**, so you can:

- **Browse** across up to 4 browser lanes without losing tabs
- **Think & write** with chat + one-click text improvement + reusable prompts
- **Organize** notes, files, and knowledge folders in one place
- **Execute** repeatable work with agents and batch workflows
- **Analyze** data in notebooks with guided AI help

> You don't need to learn 100 features. Start with one lane + one chat. Add automation when you're ready.

## 🖥️ What you can do — 9 pillars, 100+ capabilities

### 1. Browse — 4-lane multi-browser workspace (B1–B4)
**Useful when:** comparing sources, drafting from research, keeping chat + docs visible together.

- Up to 4 live browser lanes with single / dual / triple / quad layouts
- Flexible split views — research left, writing right
- Lane-to-lane relay — move readable content between lanes in one click
- One-click readable capture (Grab) into Notes
- Full history + download manager built into the workspace
- Session layouts — save and restore your window arrangement
- Smart hibernation — idle lanes sleep to keep Windows fast
- Navigation shortcuts + recovery if a page stalls
- **You get:** less tab chaos, faster compare-and-copy, no lost context.
### 2. Chat — cloud + local conversations that stay useful
**Useful when:** drafting, summarizing, brainstorming, translating, explaining.

- Cygnal Chat with history, file attachments, and image understanding
- Direct Chat + Ollama chat for fully local conversations
- Temporary chat for throwaway questions (nothing saved)
- Chat sessions you can rename, reopen, and continue
- Rich answers: tables, code blocks, math equations, diagrams (Mermaid), artifact previews (HTML/CSS/JS)
- Copy broker, preview box, and export options for moving answers into notes/docs
- Offload long chats to keep the app snappy
- **You get:** a writing partner that remembers context and hands you clean output.

### 3. Create — notes, docs, and reusable prompts
**Useful when:** building a knowledge base, writing reports, saving what works.

- Rich Markdown notes with tables, checklists, and equations
- Markdown editor with live preview + full-screen focus
- Notes organized by project → folder → note
- Export notes to Markdown / HTML / Word / PDF for sharing
- Note asset compression + image resize / crop / optimize built in
- Prompt Library with 100s of starter prompts + proven methodologies:
  - Prompt engineering (generator, few-shot, role/persona, constraints)
  - Strategy (SWOT), Marketing (AIDA), Productivity (Pomodoro), Storytelling (HALO)
  - Prompt variables + text expansion — type short, expand to full instruction
### 4. Automate — agents & batch workflows that run while you work
**Useful when:** repeating the same research, formatting, or data task over and over.

- Reusable agents for common tasks
- Batch workflows across lanes and files
- Run repeatable jobs while you keep working
- **You get:** your time back from repetitive work.

### 5. Analyze — Jupyter notebooks with guided AI help
**Useful when:** exploring data, building charts, running stats.

- Notebooks with guided AI assistance
- Charts and tables rendered inline
- **You get:** analysis without fighting tooling.

### 6. Organize — knowledge folders & file management
**Useful when:** keeping research, notes, and assets in one place.

- Project → folder → note hierarchy
- Knowledge folders with semantic search
- **You get:** everything findable in seconds.
